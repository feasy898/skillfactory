# mm-t05 · 解析边缘行的正则口径 vs 领域直觉

## 任务

把 `task.json.input` 转写稿保存为 `heping_campus_1112.txt`，整理成三段式会议纪要写入 `<outdir>`。本稿混有若干格式边缘行：哪些进产物、哪些是噪声，**以技能包解析正则的口径为准**（`^\[(\d{1,2}:\d{2})\]\s*([^：:]+?)\s*[：:]\s*(.+?)\s*$`），不以日常时间常识为准。

## 判定要点（期望值已用包内 minutes.py 实测校准，全部可机判）

期望：决议 2 / 待办 4 / 风险 1，合计 7；元信息行「解析发言 7 条」。

| 行 | 处置 | 正则口径理由 |
|---|---|---|
| `[9:5] 保卫部: 例行巡逻开始` | **排除** | 分钟 1 位，`\d{2}` 不匹配 → 解析失败噪声 |
| `[10:60] 后勤组: 场地需要预订` | **收录·待办①** | 分钟 60 值越界**但格式合法**（`\d{2}` 不校验 00-59）→ 正则接受，内容含「需要」→ 待办（两列均待定）。**按时间常识排除该行=判错** |
| `[11:05] 副队长(代:何莉): 值班表需要更新` | **收录·待办②** | 正则把说话人截到第一个冒号前=「副队长(代」，内容=「何莉): 值班表需要更新」→ 解析成功且内容含「需要」→ 待办。条目前缀必须逐字为 `2. 【11:05 · 副队长(代】何莉): 值班表需要更新` |
| `[11:06] 何莉: 值班表下月启用新版本` | 排除 | 解析成功但零关键词（「下月」是期限词不是分类词） |
| `[11:07] 何莉: 我们决定值班周期从双周改为单周` | 决议① | 「决定」 |
| `[100:00] 门卫办: 秋冬季巡逻需要加频` | **排除** | 小时 3 位（至多 2 位）→ 解析失败噪声 |
| `[11:09] 老佟: 供暖设备巡检需要挂牌，截止到本月底` | 待办③ | 「需要」；期限=本月底；负责人待定 |
| `[11:10] 何莉：同意，巡检记录用新表格` | 决议② | 全角冒号「：」分隔合法；「同意」 |
| `[11:12] 老佟: 消防通道堆物现象有延期整改的记录，风险不小` | 风险① | 「延期」「风险」 |
| `散会前提醒：下周一开始穿工服` | 排除 | 无时间戳，无法解析 |
| `[11:15] 老佟: 需要补充两名夜班门卫` | 待办④ | 「需要」；两列待定 |
| `[11:16] 何莉: 今天到这，散会` | 排除 | 零关键词 |

## 判挂点

- `[10:60]` 或冒号截断行被按「常识」排除（判「60 不是合法分钟」「说话人里有冒号所以这行坏了」）→ 正确性错行——规则口径只有「正则匹配与否」，没有「值域/语义合理性」检查。
- `[9:5]`、`[100:00]` 被收录（内容含「需要」）→ 同样错行：这两个才是真解析失败。
- summary 应为 2/4/1/7。
