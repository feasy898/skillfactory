# mm-t04 · 关键词词面多义边界

## 任务

把 `task.json.input` 转写稿保存为 `xiangqi_fashion_1009.txt`，整理成三段式会议纪要写入 `<outdir>`。分类只按技能包关键词表的**子串包含**判定（决议：决定/议定/同意/结论；待办：需要/负责/跟进/截止；风险：风险/延期/不确定），优先级 决议 > 待办 > 风险，一行至多一类。

## 判定要点（优先机判）

期望：决议 3 / 待办 3 / 风险 2，合计 8。

| 行 | 含关键词（词面） | 归类 |
|---|---|---|
| 10:01 | 「报**销同意书**的审批流**需要**…」 | 决议（「同意」在「同意书」中命中，决议 > 待办，虽然「需要」也在） |
| 10:02 | 「**延期**赔偿口径…**需要**传达」 | 待办（决议词无；待办词「需要」先于风险词「延期」） |
| 10:03 | 「尺码的**结论**性吐槽」 | 决议（「结论」在「结论性」中命中） |
| 10:04 | 「主播冯**议定**下周的排班」 | 决议（「议定」在人名「冯议定」中命中；关键词只匹配内容，不看语义角色） |
| 10:05 | 「工单**需要****跟进**，**责任**落到车间」 | 待办（「责任」不含「负责」；负责人提取无模式 → 待定） |
| 10:06 | 「定价我不**确定**」 | 风险 |
| 10:07 | 「**需要**重新配，**截止**月底前完成」 | 待办（期限=「月底前」） |
| 10:09 | 「存在**延期风险**」 | 风险 |

排除行：10:00、10:08、10:10（零关键词）。

待办两列：10:02（待定/待定）、10:05（待定/待定——「车间」不是模式命中的负责人）、10:07（待定/月底前）。

## 判挂点

- 「同意书」「结论性」「冯议定」任一行被按语义排除 → 正确性错行。
- 10:02 被归风险（被「延期」带偏）→ 优先级违反。
- 10:05 负责人填「车间」→ 编造。
