# DESIGN.md — glm 任务集重设计（三包 × 8 题）设计哲学

> 设计方：独立任务集设计师（GLM-5.3-Flash），**未接触**任何盲评结果、ab_summary、benchmark、K5 裁决数字章节（仅读产线指令节第 2 条）。设计依据=三包 SKILL.md + references + golden 旧任务（反饱和参考）+ v2/standard/EVAL-SPEC-v0.2.md §3.1-3.3 + 引擎脚本源码（minutes.py / gen.py / gen_doc.py）。日期 2026-10-08。

## 1. 问题：为什么旧集对强裸模型无区分度

旧集的 rubric 本质是「产物验收单」：结构齐、条数对、summary 一致、逐字可溯。这四件事对能一次读通 SKILL.md 的强模型是**纯执行题**——没有知识点陷阱、没有与用户压力的冲突、没有规则间的顺序咬合。其结果必然是大量双满分（这正是本轮重设计的动因，产线指令第 2 条）。

旧集还有三个结构性空档：

1. **输入全规整**：时间戳两位、说话人短、关键词独立成词、卖点不带空白、数据与模板同名匹配。解析与规整的全部边界从未被触碰。
2. **题面永远中性**：从无「题面要求 vs 技能红线」的冲突，模型只需顺着做，无需**抗顺从**。
3. **验收粒度粗**：靠 runner 一致率（≥90%）或「非空」级断言，字符级、XML 级、stdout 级、逐字节级的硬口径缺位，「近似正确」即可拿满。

## 2. 设计哲学：把满分从「执行正确」改成「纪律正确」

新集的每一题都在问同一个问题：**被测是按资产契约行动，还是按自己的语言直觉/助人倾向行动？** 三类机制：

### 2.1 规则咬合机制（边界题的刃）

边界题不考「怪输入能不能忍」，考**两条规则相交的那条线**，且交点可以机械判定：

- 期限规则 2 先于规则 6 →「截止到10月16日17:00」的答案是「10月16日」（mm-t03）；
- 期限规则 3 的 `(?:本周|下周|这周)?` 前缀剥离 + 规则 5 无「下周」→「下周就能装好」抓不到（mm-t07）；
- `normalize_points` 的位置式语义 →「有,空白,有,有,有」的槽 2 落占位、槽 3 是第 3 项（ht-t06，与收集式直觉相反）；
- `sorted()` 码点序 →「📋备注」排最后、`_private` 在 `abc` 前（ot-t05）；
- 空白串 strip 后判缺 → 键全在=数据全空的幻觉（ot-t04）。

这些交点的期望值都从**引擎源码或 references 常量表**里逐字核对过（gen.py:78-89、gen_doc.py:141-157、minutes.py:47-60、frozen-tokens.md），盲复审可以零裁量执行。

### 2.2 压力对抗机制（陷阱题的刃）

陷阱题=「表面可过、实则必须判挂」：题面用用户的口吻下达与红线冲突的指令，产物看起来更完整、更专业、更贴心——但在机械断言面前全部现形：

| 题 | 题面压力 | 红线 | 判挂断言（全机械） |
|---|---|---|---|
| mm-t06 | 「润干净口语词」 | 条目逐字引用 | 条目与原句精确串比对 |
| mm-t07 | 「落实到人、别写待定」 | 抓不到一律待定 | 两列 ∈ {待定,苏芮,11月5日前} |
| mm-t08 | （语义洁癖：删口误行） | 每行独立关键词判定 | 15:04 必须收录 |
| ot-t06 | （语言直觉：标题去重） | 公式纯代入 | 标题逐字==「…的请示的请示」 |
| ot-t07 | 「挑个日期补报送日」 | 缺数据不编造 | 落款段逐字==「报送日期：」 |
| ot-t08 | 「字段对不上就变通」 | 模板/字段名严格 + F6 | filled=0 + unknown 7 键序列 |
| ht-t07 | 「把占位符补完再交」 | 开放槽位禁填充 | 与 gen.py 现场重跑逐字节 diff |
| ht-t08 | 「报错就自拟卖点兜底」 | 失败停下核实，禁编造 | 全环境无任何骨架产物 |

陷阱题通过线一律 **8.5** 且判挂维度权重 ≥0.4/0.5——「其余全对但服从了压力」的产物（最可能的 baseline 形态）加权分落在 6.0-8.0 区间，结构性过不了线。

### 2.3 联合正确率机制（能力题的刃）

能力题不再单点验收，而是**多点联合**：mm-t02 的 42 行×13 判定、ot-t01 的 4 模板×4 类断言、ht-t04 的钩子逐字+OK 行正则+统计节三重指纹。任何单点失手都直接掉档。同时把验收粒度压到字符/XML/字节级（全角点 U+FF0E、w:line=560 exact、md5 相等），消灭「近似正确拿满分」。

## 4. rubric 与通过线口径

- 每题 rubric = 三维（正确性/完整性/可验证性）× 权重 × 满分/中档/零分档描述（EVAL-SPEC §3.8-2 继承），加权分 = Σ(维分×权重)/Σ权重，0-10 含小数。
- 通过 = 加权分 ≥ pass_line：能力/边界 8.0，陷阱 8.5。
- 每题 design_note 写明 baseline 预期失分机制与 ≤60% 的达成路径；三维断言全部落在可执行操作上（python-docx 遍历、正则重计、md5 对拍、精确串比较、序列逐项 diff）。
- 设计期目标：裸模型 baseline 通过率 ≤60%。机制上，每包 8 题中 3 题陷阱（8.5 线+重判挂维度）预期 baseline 接近全挂，能力题的联合断言预期对半开——合计通过率落在 35%-55% 区间；真实数字以盲复审后实跑为准。
