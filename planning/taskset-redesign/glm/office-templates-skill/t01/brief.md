# ot-t01 · 四类模板标题公式/称谓/落款形态矩阵 + XML 级版式硬断言

## 任务

`task.json.input.files` 内含四类文书的数据 JSON（周报/请示函/会议通知/工作总结）。将它们分别保存为 `<workdir>/周报.json` 等四个文件，用 office-templates 技能分别生成到：

- `<outdir>/周报/`、`<outdir>/请示函/`、`<outdir>/会议通知/`、`<outdir>/工作总结/`

每目录恰含 `文书.docx` 与 `fields.json`。

## 判定要点（全部可机判，python-docx + XML 断言）

1. **标题公式**（4 份 fields.json.title 与 docx 首个非空段逐字相等，且=）：
   - `拾贝书店工作周报`
   - `关于采购档案消毒柜的请示`
   - `关于召开秋季会员茶话会的通知`
   - `屿光咖啡品控组2026年第三季度工作总结`
2. **称谓矩阵**：请示函第二非空段=`澜山物业管理有限公司：`（顶格、全角冒号收尾）；会议通知第二非空段=`全体会员：`；周报与工作总结**无称谓段**。
3. **落款形态**：周报末个非空段=`报送日期：2026-10-12`（一行带标签）右对齐；请示函两行=`澜山物业综合管理部`+`2026年10月12日`（裸日期）；会议通知两行=`青蘅茶社`+`2026年10月9日`；工作总结两行=`屿光咖啡品控组`+`2026年10月9日`——落款段均为右对齐。
4. **XML 级正文版式**：每份 docx 存在正文段满足 `w:firstLineChars=200`；标题段 eastAsia 字体=黑体、字号 22pt（`w:sz=44`）；正文 run eastAsia=仿宋、16pt、ascii/hAnsi=Times New Roman；固定行距 28 磅（`w:spacing w:line=560 w:lineRule=exact`）。
5. **台账**：四份 fields.json 顶层 7 键、summary 6 键，filled=total（7/7、8/8、11/11、7/7），missing=0，计数自洽。

## 判挂点

标题少字/多字、称谓段错位或缺失、落款日期带「成文日期：」标签（除周报报送日期外落款日期行为裸日期）、行距用 1.5 倍行距代替固定 28 磅——任一处即相应维度降档。
