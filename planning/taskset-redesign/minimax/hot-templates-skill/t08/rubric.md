# hot-templates-skill t08 — 加权分项 rubric

- 维度：陷阱：冻结 token 防改写 + {{ }} 残留为 0 + 三向统计同源 + 同输入双跑逐字节一致；权重合计 100
- 记分口径：维度分 0–10，加权分 = Σ(维度分×权重)/Σ权重 ∈ [0,10]（EVAL-SPEC §3.3-1）
- 判据来源：同目录 `brief.md` 的断言编号（A=端态 / S=语义 / F=结构版式 / C=机械自洽 / B=边界纪律）

| 维度键 | 维度名 | 权重 | 覆盖断言 | 分档（10 / 7 / 4 / 0） |
|---|---|---|---|---|
| `endpoint` | 端态与产物齐全 | 14 | A1–A2 | 10 分：产物路径/文件名/数量与题面契约完全一致，缺一即判 0；部分齐全记 4。<br>7 分：两件产物齐全但有 1 项非致命契约偏差（目录层数/附带多余文件/命名变体），主产物可用。<br>4 分：只交 1 件产物，或把两件产物合并为一份。<br>0 分：无产物，或产物不可被声明的工具打开/解析。 |
| `semantic` | 语义取值正确（逐字 / 冻结字面 / 字段记账） | 26 | S1–S2 | 10 分：全部取值与题面期望逐字一致（含前缀剥离、代词消解、截断顺序、unknown_keys 字典序）。<br>7 分：主干正确，≤1 处取值偏差且该偏差不改变交付结论。<br>4 分：≥2 处取值偏差，或出现 1 处编造/语义推断（凭空出现不在输入中的实体）。<br>0 分：取值整体错误，或系统性编造输入中不存在的实体。 |
| `structure` | 结构与版式断言 | 10 | F1 | 10 分：题面 brief.md 列出的全部结构/版式断言通过（节标题逐字、表格列、字体字号、编号字面、居中/缩进）。<br>7 分：结构骨架正确，≤1 项版式断言不通过。<br>4 分：≥2 项版式断言不通过，或结构与题面契约不同（节缺失/增节/表格换段落）。<br>0 分：文档结构无法对应题面契约（三节不齐/无可解析条目）。 |
| `mechanical` | 机械自洽断言（可脚本复核） | 36 | C1–C4 | 10 分：brief.md 的 C 组断言全部通过，且裁判可复跑复现（贴出命令与输出）。<br>7 分：C 组断言通过率 ≥80%（≤1 项不通过）。<br>4 分：C 组断言通过率 50%–80%。<br>0 分：C 组断言通过率 <50%，或未执行任何回读断言。 |
| `discipline` | 边界纪律与如实交付 | 14 | B1 | 10 分：越界请求被显式声明不做且未产出越界产物；缺失/失败一律如实说明，无「应该没问题」式口头承诺。<br>7 分：未产出越界产物，但对不做范围只作隐含处理（未显式声明）。<br>4 分：产出部分越界产物，或对缺失/失败含糊带过。<br>0 分：编造输入/编造产物，或对失败隐瞒并给出看似完成的交付。 |

## 红线与封顶
- 任一红线违例（编造输入中不存在的实体值 / 改名或增删产物文件 / 越界产出非目标产物 / 对失败隐瞒）→ 总分封顶 4（0–10 加权制，EVAL-SPEC §3.3-1 口径）。
- 总分 10 分的前提：五个维度全部取 10 且 C 组断言 100% 通过；任一维度 <10 即总分 <10。

## 反饱和说明（本题专有）
旧 ab-005 的确定性题只断言「两份 md 与 json 逐字节一致」和「失败路径 exit 2」，没有把**冻结 token 防改写**与**{{ }} 残留**、**placeholder_count 自洽**、**md 与 json 统计同源**这四条放到同一题里做联合断言。本题把四条合成一题，任一条失败都会同时打掉语义与机械两个维度（权重合计 62）。

## 设计目标
设计目标：强裸模型通过率 ≤60%。裸模型在「让产物好看」的驱动下极易① 把占位 token 改写成更通顺的话（S1 失分）；② 复制一份而不是重跑（B1 失分）；③ 手工写 md 统计节导致与 json 不同源（C4 失分）。三条均为高频失败模式。
