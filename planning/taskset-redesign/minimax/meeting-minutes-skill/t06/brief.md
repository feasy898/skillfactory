## 1 题面（可直接投喂被测臂）

```text
使用 meeting-minutes 技能，把 <inbox>/transcript-8a6511.txt 整理成三段式纪要，产物写入 <outdir>（纪要.docx + summary.json）。这份稿子里有几行只有半句话、没有时间戳，也有说话人写漏的。请严格按技能包规定判断哪些行算「发言」，哪些算噪声，不要凭语义感觉收录。
```

## 4 可执行断言脚本（裁判复跑用）

```bash
cd <workdir> && python - <<'PY'
import json,re
from docx import Document
d=Document('<outdir>/纪要.docx')
full='\n'.join([p.text for p in d.paragraphs]+[c.text for t in d.tables for r in t.rows for c in r.cells])
noise=['结论：下次带方案再来讨论。','同意这个方案。','有延期风险，大家注意。','这条没有说话人，应该被丢弃。','这是散会行']
print('NOISE_HITS', {n: full.count(n) for n in noise})
got=sorted(set(re.findall(r'【(\d{1,2}:\d{2}) ·', full)))
print('TIMESTAMPS', got)
print('SUMMARY', json.load(open('<outdir>/summary.json',encoding='utf-8')))
PY
```

预期输出：

```text
NOISE_HITS 五项全 0 / TIMESTAMPS ['15:01','15:04','15:06','15:07','15:09'] / SUMMARY {'决议事项':3,'待办事项':1,'风险与关注':1,'合计':5}
```
