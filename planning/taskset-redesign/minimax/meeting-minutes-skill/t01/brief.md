## 1 题面（可直接投喂被测臂）

```text
使用 meeting-minutes 技能，把 <inbox>/transcript-8a6511.txt 这份会议转写稿整理成三段式纪要，产物写入 <outdir>，必须含 <outdir>/纪要.docx 与 <outdir>/summary.json。本稿的时间戳写法不统一（有一位的时、也有两位的时），分隔冒号中英文混用，有一个说话人的名字里带间隔点。请按技能包规则原样解析，不要自创格式，也不要把任何一句发言改写或概括。
```

## 4 可执行断言脚本（裁判复跑用）

```bash
cd <workdir> && python - <<'PY'
import json,re
from docx import Document
d=Document('<outdir>/纪要.docx')
paras=[p.text for p in d.paragraphs]
meta=[p for p in paras if p.startswith('来源：')][0]
print('META_OK', bool(re.match(r'^来源：transcript-8a6511\.txt ｜ 解析发言 6 条（决议 3 · 待办 2 · 风险 1）$', meta)))
t=d.tables[0]
print('TODO_HEADER', [c.text for c in t.rows[0].cells], 'ROWS', len(t.rows)-1)
print('SUMMARY', json.load(open('<outdir>/summary.json',encoding='utf-8')))
PY
```

预期输出：

```text
META_OK True / TODO_HEADER ['事项','负责人','期限'] ROWS 2 / SUMMARY {'决议事项': 3, '待办事项': 2, '风险与关注': 1, '合计': 6}
```
