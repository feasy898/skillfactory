## 1 题面（可直接投喂被测臂）

```text
使用 meeting-minutes 技能，把 <inbox>/transcript-8a6511.txt 整理成三段式纪要，产物写入 <outdir>（纪要.docx + summary.json）。请特别留意「待办事项」表格里的「期限」列：每条待办的期限都只能按技能包的确定性规则从原句里取，取不到就填「待定」，绝对不要推断或改写成别的日期表述。
```

## 2 目标态

待办表格期限列 4 个数据格中 3 格为规则提取结果、1 格为「待定」，逐格等于期望字面。

## 4 可执行断言脚本（裁判复跑用）

```bash
cd <workdir> && python - <<'PY'
from docx import Document
t=Document('<outdir>/纪要.docx').tables[0]
exp=['2026-11-03','本季度末','材料清单','待定','星期二前']
got=[r.cells[2].text.strip() for r in t.rows[1:]]  # strip 后逐字比对
print('GOT', got)
print('DEADLINE_ALL_OK', got==exp)
PY
```
