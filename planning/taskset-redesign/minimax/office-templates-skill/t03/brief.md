## 1 题面（可直接投喂被测臂）

```text
使用 office-templates 技能，分别把 data/请示函/case1.json、data/会议通知/case1.json、data/工作总结/case1.json 三份数据各渲染成一份文书，输出到三个独立目录 <outdir>/请示函、<outdir>/会议通知、<outdir>/工作总结，每个目录下放该次调用的 文书.docx 与 fields.json。请严格按各模板的版式规范成文。
```

## 2 目标态

三类模板的称谓/落款/编号/行内标签四组版式细节各自成立，无串味（不得给工作总结加称谓段）。

## 4 可执行断言脚本（裁判复跑用）

```bash
cd <workdir> && python - <<'PY'
import json
from docx import Document
for t in ('请示函','会议通知','工作总结'):
    d=Document(f'<outdir>/{t}/文书.docx')
    ps=[p.text for p in d.paragraphs]
    f=json.load(open(f'<outdir>/{t}/fields.json',encoding='utf-8'))
    print(t, 'TITLE', repr(ps[0]), '| SIG', [p for p in ps if p.strip()][-2:], '| SUM', f['summary'])
PY
```

预期输出：

```text
三行：TITLE 逐字命中三条公式 / SIG 两行且第二行为裸日期 / SUMMARY 8-0-0、11-0-0、7-0-0
```
