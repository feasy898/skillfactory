## 判挂点

判挂点统一计分规则（复审第二轮 R1）：判挂点任一命中 → 正确性降 1 档（1.0→中档，已零档保持）+ 各关联维度按下述档位降档；编造走全包统一口径（可验证性整维 0 档 + 正确性降档）；加权分按 rubric 公式（10 × Σ(维度分×权重)/Σ权重，0-10 刻度舍 1 位）重算，必须真实跌破通过线。

- 「同意书」「结论性」「冯议定」任一行被按语义排除 → 正确性错行（0.5 档）⟦正确性=0.5,完整性=1.0,可验证性=1.0⟧ → 0.25+0.3+0.2=0.75 → 7.5 < 8.0。
- 10:02 被归风险（被「延期」带偏）→ 优先级违反（0.5 档）⟦正确性=0.5,完整性=1.0,可验证性=1.0⟧ → 0.75 → 7.5 < 8.0。
- 10:05 负责人填「车间」→ 编造（全包统一口径：可验证性整维 0 档 + 正确性降档）⟦正确性=0.5,完整性=1.0,可验证性=0⟧ → 0.25+0.3+0=0.55 → 5.5 < 8.0（复审第二轮 R1：原「可验证性 0」=0.80 恰过线，已修）。
