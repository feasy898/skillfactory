## 判挂点

判挂点统一计分规则（复审第二轮 R1）：判挂点任一命中 → 正确性降 1 档（1.0→中档，已零档保持）+ 各关联维度按下述档位降档；编造走全包统一口径（可验证性整维 0 档 + 正确性降档）；加权分按 rubric 公式（10 × Σ(维度分×权重)/Σ权重，0-10 刻度舍 1 位）重算，必须真实跌破通过线。

- 4 条形似待办零关键词行任一混入待办节 → 正确性错行（0.5 档）⟦正确性=0.5,完整性=1.0,可验证性=1.0⟧ → 0.25+0.3+0.2=0.75 → 7.5 < 8.0。
- 14:25 负责人写成「她/说话人」→ 编造（全包统一口径：可验证性整维 0 档 + 正确性降档）⟦正确性=0.5,完整性=1.0,可验证性=0⟧ → 0.25+0.3+0=0.55 → 5.5 < 8.0。
- 14:12 期限多带「15号」、14:16 负责人漏抓 → 对应格错（判挂点主考点）：可验证性该格错（0.5 档）+ 正确性降档 ⟦正确性=0.5,完整性=1.0,可验证性=0.5⟧ → 0.25+0.3+0.1=0.65 → 6.5 < 8.0（复审第二轮 R1：原「对应格错」按可验证性中档计得 9.0 过线，与 design_note「本月/芦芽字面提取陷阱」定位矛盾，已改主考点口径）。
