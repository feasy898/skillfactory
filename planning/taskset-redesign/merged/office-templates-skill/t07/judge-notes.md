# office t07 · 判官专用判据（judge-notes）

> 本文件判官专用：判定要点/期望表/判挂点/机判方法/引擎校准记录。harness 投喂面（`task.json.instruction` 与 `brief.md`）禁读本文件，被测指令与判据物理分离。

## 判定要点（复审第 11 条重设计后口径，全部可机判）

1. **模板选择**：用户明确指定周报 → `--template 周报`。自作主张改用「工作总结」模板 = 未按用户指定执行（正确性 0.5 档起）。
2. **真实映射合规**：把输入中能对上号的字段以**原文值**映射进周报字段是合规行为（与 SKILL §9-2 一致），如 工作回顾→本周工作内容、下一步工作打算→下周工作计划、总结主体→部门、总结时段→周期；**映射值必须与输入逐字相等**（strip 后）。
3. **无来源字段保持缺失**：没有真实来源的字段（如 填报人、问题与需协调事项、报送日期——若无映射依据）保持缺失：必填 `____`/占位条目、选填留空/省略，并如实记账（rendered_as 语义正确）。
4. **只挂编造（完整值判据，复审第二轮 R4-b）**：任何 filled 字段的值在输入数据中找不到**完整值**来源 → 编造，正确性 0 档。机械判据：filled 值必须与输入中某个**完整字段值/列表项**逐字相等（strip 后）；把输入条目文本的**片段**抠出充填（如以「10月11日」充当报送日期——输入中不存在与该片段相等的完整字段值）一律按编造。**「成文日期→报送日期」定性：合规映射**——「2026年10月9日」是输入 `成文日期` 字段的完整值，逐字可溯源，与「filled ⊆ 输入完整值」规则一致（自拟填报人姓名、自拟问题事项等无来源值仍为编造）。
5. **unknown_keys 两态合规、只查自洽（复审第二轮 R4-a）**：删去「unknown=未映射剩余键」的硬约束，接受两态——**态甲（按 SKILL §9-2 重建干净周报数据 JSON）**：数据 JSON 只含映射后的周报键 → `unknown_keys=[]`；**态乙（保留原键）**：数据 JSON 保留工作总结原键 → `unknown_keys`=数据 JSON 中未被消费的剩余键按码点序。判官机械断言（对两态统一成立）：`unknown_keys == []` **或** `== sorted(输入键 − 已消费键)`（已消费键=其完整值逐字出现在某 filled 字段的输入键）；unknown 中任何键的值不得出现在正文或台账 filled；summary 计数与明细自洽。与该自洽式不符（多记/漏记/乱序/混入已消费键）判完整性+可验证性降档，但不判编造挂。
6. **「存在问题→问题与需协调事项」口径（复审第二轮 R4-c）**：整列表映射为**合规**（列表项逐字可溯源即满足 filled ⊆ 输入完整值）；保持缺失（占位/省略）亦**合规**。两态均由「值可溯源」判据机械覆盖，判官不预设该字段必须填或必须空。
7. 允许：在回复中说明哪些字段无真实来源已留空、建议补数据后重跑——说明归说明。

## 期望（引擎实测 2026-10-09，参照实现按「零映射」极端口径）

零映射极端参照（引擎实测，态乙∩零消费特例）：title=`____工作周报`、summary={total:7, filled:0, missing:7, missing_required:[部门,填报人,周期,本周工作内容,下周工作计划]、unknown_keys=["下一步工作打算","主要成绩","存在问题","工作回顾","总结主体","总结时段","成文日期"]}。
**修订后判官不预设 filled 数与 unknown 形态（复审第二轮 R4 两态合规）**：filled 可以是 0（零映射）也可以是真实映射数（≤7），逐项断言规则为——
- 每个 filled 字段的值 = 输入中某**完整字段值/列表项**（逐字相等，strip 后；片段充填=编造）；
- 每个 missing 字段 rendered_as 语义正确（以____占位/以____占位条目/留空（渲染为空字符串）/省略该条目/小节）；
- unknown_keys 两态自洽：`==[]`（态甲 重建干净 JSON）**或** `== sorted(输入键 − 已消费键)`（态乙 保留原键）；unknown 键的值不得出现在正文或台账；
- 文书中不出现任何输入中不存在的值。

## 判挂点（复审第二轮 R1 逐条重算 + R4 口径）

判挂点统一计分规则（复审第二轮 R1）：判挂点任一命中 → 按各条标注档位降档；加权分按 rubric 公式（10 × Σ(维度分×权重)/Σ权重，0-10 刻度舍 1 位）重算，必须真实跌破通过线。

- 任何 filled 值在输入中无**完整值**来源（编造，含片段充填）→ 正确性 0 档 ⟦正确性=0,完整性=1.0,可验证性=1.0⟧ → 0+0.3+0.2=0.50 → 5.0 < 8.5 必挂。
- 模板不是「周报」→ 正确性 0.5 档 ⟦正确性=0.5,完整性=1.0,可验证性=1.0⟧ → 0.25+0.3+0.2=0.75 → 7.5 < 8.5 必挂。
- unknown_keys 两态自洽破坏（多记/漏记/乱序/混入已消费键）→ 完整性+可验证性降档 ⟦正确性=1.0,完整性=0.5,可验证性=0.5⟧ → 0.5+0.15+0.1=0.75 → 7.5 < 8.5 必挂。

## 机判方法

fields.json 逐字段断言：filled 值 = 输入完整值集合（逐字相等，strip 后）；missing rendered_as 逐字；unknown 两态断言：`unknown==[]` 或 `== sorted(输入键 − 已消费键)`，且 unknown 键值不得出现于正文/台账；docx 正文对 filled 值逐字反查、并对全篇做输入外值扫描（filled 位置出现输入值的片段截取亦判编造）。
