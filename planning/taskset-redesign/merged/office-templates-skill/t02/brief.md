# ot-t03 · 会议通知满字段成文细节

## 任务

把 `task.json.input.data` 保存为 `qingheng_teahui.json`，用 office-templates 技能以模板「会议通知」生成到 `<outdir>/`（`文书.docx` + `fields.json`）。

## 判定要点（全部可机判）

1. **标题**：`关于召开秋季会员茶话会的通知`，居中、黑体 22pt。
2. **称谓**：第二非空段=`全体会员：`，无首行缩进，全角冒号收尾。
3. **议题 strip**：正文议题行逐字等于 `会议议题：秋季茶会流程与冬至茶会预告`（标签+strip 后值，实测校准的渲染形态）；fields.json 议题 value 同为 strip 后字符串——原文首尾空格不得进入产物。
4. **会议要求小节**：节头含「一、」前缀（列表小节编号）；6 个条目以**全角点**编号 `1．…` 至 `6．…`（U+FF0E，非半角 `1.`），条目文本与数据逐字一致、顺序保持。
5. **正文版式**：正文段首行缩进两字符（`w:firstLineChars=200`）、eastAsia=仿宋 16pt、固定行距 28 磅。
6. **落款**：末两个非空段=`青蘅茶社`、`2026年10月9日`（裸日期、无标签），右对齐。
7. **台账**：filled=11/missing=0/total=11；filled 明细 value=strip 后值；联系人行与联系电话行在文中可见。

## 判挂点

- 议题以 ` 秋季茶会流程与冬至茶会预告 `（带空格）进入文书或台账 → strip 失守。
- 条目编号用半角 `1.` 或 `1、` → 编号规范错。
- 落款日期写成 `发文日期：2026年10月9日` → 标签违规（应裸日期）。
