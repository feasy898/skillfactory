## 二、这个包能干什么（使用者视角）

### 典型用法
给 agent 一份结构化 JSON，它输出一份排版合规的 .docx：

```bash
python scripts/gen_doc.py --template 周报 --data case1.json --outdir out
# → out/文书.docx（公文版式）+ out/fields.json（字段台账）
```

输入长这样（周报）：
```json
{"部门":"研发部","填报人":"王小明","周期":"2026-09-21 至 2026-09-27",
 "本周工作内容":["完成打分器 v0.9 与评测台联调","修复评测集 3 处标注不一致问题"],
 "下周工作计划":["启动回归测试全量跑批","输出周度质量报告初稿"],
 "问题与需协调事项":["测试机资源紧张，需协调一台 GPU 机器"],
 "报送日期":"2026-09-28"}
```

### 两条设计红线（它区别于"让大模型随手写公文"的地方）
1. **缺数据不编造**：必填字段缺失用 `____` 占位，选填缺失留空或整节省略，并在 fields.json 里如实记账。
2. **产物确定性可复现**：同一输入连跑两次，`文书.docx` 与 `fields.json` **整文件逐字节一致**
   （引擎把 docx 容器时间戳归一化，无墙钟/随机源）。

### 适用范围与不适用范围（SKILL.md 明示）
- **适用**：四类规范化文书的成文、可程序验收的批量成文、需如实报告字段缺失情况的交付。
- **不适用**：模板定制/字段增删/多文档合并、docx→pdf、红头文件/公章/版记、
  数据语义校验（日期格式、电话号码按原样字符串处理）、文辞润色。

| 字节级可复现 | 同输入双跑 sha256 | **完全相同**（`b9752143…` ×2） |

### 3.2 真实模型对照评测（13 任务 × 2 族 × 2 臂 × 3 重复 = 78 次调用）
评测设计：同一题给两组模型跑——**治疗臂**（挂本技能）与**裸臂**（不挂），比产物质量。

| 门 | 阈值 | 实测 | 结果 |
|---|---|---|---|
| 增益 Δ | ≥ 1.0 | **+4.59** | 过 |
| 任务级胜率 | ≥ 60%（13 题需 ≥8 胜） | **92.31%（12 胜 1 平 0 负）** | 过 |
| 反向任务 | ≤ 1 | **0** | 过 |
| 效率（token/耗时比） | ≤ 2.0 | **0.473 / 0.375** | 过 |
| 可判性 | 13/13 | **13/13** | 过 |

被测模型钉版：GLM-5.3@bigmodel（max 档）与 Minimax-M3.1-Flash-Preview（enabled 档）双族；
裁判：三族异族互裁盲态（每任务 ≥2 位异族裁判，位置轮换）。

### 3.3 资产回炉闭环（这是本包最重要的历史）
2026-10-08 首次 K-5 评审被拒。alpha 查明根因是**资产真缺陷**：
python-docx 会把当前墙钟时间写进 docx 容器的 17 个 zip 条目，导致同一输入连跑两次
产物 sha256 不同（实测隔 5 秒双跑 `a0bc9edb` vs `41d22375`）。
修复方式：引擎新增 `canonicalize_docx_zip()`，把容器时间戳归一化为 1980-01-01；
SKILL.md 增补自评留痕规程。修复后 ab5 关键任务得分从 4.5 升到 **8.75**（达标线 7）。

2. **历史数据跨代不可比**：2026-09-30 那轮（Δ+1.20）用的是弱模型基线，与本轮强模型基线
   不同代，**不得对位或合并成区间**。两轮结论均为 rejected（第一轮）或 accepted（本轮），
   已按代分节如实披露。

   经独立复核：盲态未破、污染仅限同一裁判同一 brief、结果在首轮干净会话中已被独立复现，
