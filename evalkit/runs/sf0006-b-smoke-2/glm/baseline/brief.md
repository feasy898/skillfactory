# 任务：为一场项目例会产出三节式会议纪要

## 输入

- `fixtures/transcript.txt`：一场项目例会的转写稿。每行格式为 `[HH:MM] 说话人: 内容`。

## 输出（写到 `out/` 目录）

**1. `out/纪要.docx`（Word 文档）**

- 第一段为纪要标题（自拟，含会议主题即可）；
- 正文依次包含三节，节标题必须逐字为：`一、决议事项`、`二、待办事项`、`三、风险与关注`；
- 「决议事项」「风险与关注」两节的条目编号列出，每条格式逐字遵循：

  ```
  N. 【类别 · 相关人】内容
  ```

  其中 `类别` 为该节名去掉序号与顿号（即 `决议事项` 或 `风险与关注`），`相关人` 必须是转写稿中出现过的说话人姓名，`内容` 必须与转写稿中某句话逐字一致（不含句末句号也可以）；
- 「待办事项」用表格呈现：表头三列逐字为 `事项`、`负责人`、`期限`；一行一条待办；
  - `事项` 必须能在转写稿中逐字找到出处；
  - `负责人` 必须是转写稿中出现过的说话人姓名；
  - `期限` 取该条待办在转写稿中提到的时限；转写稿未提到时限的，`期限` 填 `未明确`。

**2. `out/summary.json`**

```json
{"决议事项": <条数>, "待办事项": <条数>, "风险与关注": <条数>, "合计": <三者之和>}
```

四个键名逐字如上；计数必须与 docx 中各节实际条目数一致。

## 纪律（判定即按此执行）

- 以转写稿为**唯一事实来源**：不得编造任何转写稿中不存在的决议、待办、风险、人名、时间或金额；
- 归纳、改写、概括均视为不可溯源，会被判不合格——条目内容必须逐字取自转写稿。

## 环境

- 可用 Python（python-docx 已安装）生成 docx；无需联网。
