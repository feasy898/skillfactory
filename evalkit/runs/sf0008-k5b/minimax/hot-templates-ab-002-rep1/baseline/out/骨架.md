# 小红书图文 · 爆款骨架

- 主题：租房避坑指南
- 平台模板：小红书图文（标题带数字 + emoji 规则 + 正文分块 + 标签组）
- 卖点输入：5 条（`签约前查房东房产证与身份证一致性` / `押金条款写明退还条件与时限` / `入住当天拍照录像留档` / `水电燃气表底数写进合同附件` / `转租条款提前约定违约金`）

> 本文件只给结构与开放槽位，`【占位:…】` 处为待扩写的内容，扩写时不得改动本骨架的要素顺序与标题形式。

## 1. 标题（带数字）

**标题**：`租房前必看｜5 个避坑细节，少踩一个都算赢 🏠`

- 数字位：`5`，与正文分块条数一致，禁止改成与分块数不符的数字
- 句式：`人群/场景 + 分隔符 + N 个 + 收益承诺`，前半说给谁看，后半给理由
- 长度：≤ 20 个汉字，平台列表页不截断
- 备选标题：`【占位:标题备选二】`
- 备选标题：`【占位:标题备选三】`

> 写法要点：标题是唯一决定打开率的一句，数字必须真实兑现（正文恰好 5 块）；不用「最」「第一」等绝对化表述，收益承诺要克制到可被正文证明。

## 2. emoji 规则

| emoji | 用于 | 出现位置 |
|---|---|---|
| 🔥 | 开场钩子 | 每篇仅 1 次，位于正文第一行行首 |
| ✅ | 正确做法 / 分块序号 | 每个分块行首 1 个，共 5 个 |
| 💡 | 避坑提醒 / 补充说明 | 可选，每个分块最多 1 个 |
| 📌 | 收尾总结 | 每篇仅 1 次，位于正文末行行首 |
| 🏷️ | 标签组引导语 | 仅出现在标签区，不进正文 |

- 总量上限：单篇 emoji 不超过 12 个，且不得超过正文字符数的 5%
- 禁止连用（同一行 ≥ 2 个）、禁止插在数字与单位之间（写 `5 个` 不写 `5️⃣个`）、禁止在标签串内使用
- 禁止用 emoji 替代文字信息（不用 ✅ 表示「已核实」以外的状态词）

> 写法要点：emoji 在小红书只承担「扫读锚点」职能，删掉全部 emoji 后段落层级仍应成立；一旦 emoji 变成唯一信息（如靠 🔥 表达强调），说明正文没写清。

## 3. 正文分块

### 3.1 开场钩子

```
🔥 【占位:开场钩子文案】
```

- 位置：标题下第一行，独立成段
- 写法：用具体场景或踩坑后果切入，一句话点明「看完能少损失什么」，不复述标题
- 长度：2 行以内

> 写法要点：钩子承担「为什么现在要读」，代价要具体（押金、房东跑路、水电费结不清），避免「租房好难」这类无信息量的情绪铺垫。

### 3.2 分块 1 —— 签约前查房东房产证与身份证一致性

```
✅ 1｜【占位:分块一扩写文案】
💡 【占位:分块一避坑提醒】
```

- 结构：一句话说动作 → 一句说怎么做（看什么、核对什么） → 一句说不做的后果
- 建议首句：`先看房东的房产证，再看他的身份证，名字和房产证必须对得上`

> 写法要点：分块首句就是这一条的动作指令，让人扫一眼能记住；中段给可执行步骤，末句给后果或时限，形成「动作—证据—后果」三拍。

### 3.3 分块 2 —— 押金条款写明退还条件与时限

```
✅ 2｜【占位:分块二扩写文案】
💡 【占位:分块二避坑提醒】
```

- 必含要素：退还条件（什么情况全额退、什么情况扣）、退还时限（退房后几天内）、扣除方式与凭证
- 建议首句：`押金退不退、什么时候退，必须写进合同，不能只口头说`

> 写法要点：本条的落点是「写进合同」而非「谈好」，提醒读者把口头承诺变成书面条款，是本条区别于普通建议的关键。

### 3.4 分块 3 —— 入住当天拍照录像留档

```
✅ 3｜【占位:分块三扩写文案】
💡 【占位:分块三避坑提醒】
```

- 必含要素：拍照范围（墙面、家具、家电、门窗、水表电表）、录像范围（连续不剪辑）、文件留存与命名
- 建议首句：`入住当天不拍照，退租时每一样东西都能算你头上`

> 写法要点：给出「什么时候拍」与「拍成什么样才算数」两条判定标准；强调连续录像不剪辑，是这条最常被漏掉的细节。

### 3.5 分块 4 —— 水电燃气表底数写进合同附件

```
✅ 4｜【占位:分块四扩写文案】
💡 【占位:分块四避坑提醒】
```

- 必含要素：抄表时间、各项表底数字、单价确认方式、附件编号或双方签字
- 建议首句：`水电燃气表底数不是拍照留档，是要写进合同附件里`

> 写法要点：与分块 3 区分开——拍照留档是证据，写进附件是约定；结尾点明「否则结算时只能按现读数算」，把动作和后果咬合。

### 3.6 分块 5 —— 转租条款提前约定违约金

```
✅ 5｜【占位:分块五扩写文案】
💡 【占位:分块五避坑提醒】
```

- 必含要素：可转租/不可转租的约定、房东是否书面同意、违约金计算方式与上限、提前解约的交接方式
- 建议首句：`能不能转租、违约要赔多少，必须在签约时就写死`

> 写法要点：把「转租」当作签约时的条款问题而不是住进去之后的问题；给出「书面同意」这一可验证动作，避免只留口头许可。

### 3.7 收尾总结

```
📌 【占位:收尾互动文案】
```

- 内容：一句话复述「5 条都在签约前/入住当天完成」→ 引导互动（收藏 / 评论区提问）
- 长度：3 行以内，不引入正文没讲过的新信息

> 写法要点：收尾只做归纳与互动，不补充新卖点；互动指令要具体（问什么、扣什么），比「你觉得呢」更容易拿到评论。

## 4. 标签组

**引导语**：`🏷️ #租房避坑指南 #租房攻略 #租房注意事项 #新手租房 #租房合同 #看房 #押金 #转租`

- 数量：8 个，落在 3–8 的区间内
- 首标签规则：取主题「租房避坑指南」去掉标点后加 `#`，即首标签由主题派生，不由正文措辞派生
- 其余标签：从人群（新手租房 / 毕业生）、场景（看房 / 签约）、物件（押金 / 转租 / 租房合同）三个维度各取，不重复主题词
- 格式：全部带 `#`、单空格分隔、末尾不加标点

> 写法要点：标签承担搜索流量，首标签必须与主题字面一致；标签不与正文标题堆叠重复，避免被判为堆砌。
