# 抖音口播爆款内容骨架

| 项目 | 内容 |
| --- | --- |
| 平台 | 抖音（dy） |
| 选题 | 通勤时间管理 |
| 形式 | 真人口播 |
| 冻结模板 | 3秒钩子 + 痛点 + 价值点×3 + CTA |
| 预估时长 | 约 60 秒 |
| 目标人群 | 单程通勤 30 分钟以上的上班族 |
| 价值主张 | 把每天被刷掉的通勤时间，变成职场上升期的自我投资时间 |

---

## 一、3秒钩子（0-3s）

- **目标**：数字冲击 + 损失感，3 秒内让人停下手指。
- **口播**：
  > 每天通勤2小时，一年就是整整30天——你刷掉的每一条短视频，都在替别人的目标打工。
- **画面/字幕提示**：大字弹出「2小时/天 = 30天/年」，人像怼脸开讲。

## 二、痛点（3-15s）

- **目标**：场景复刻 + 情绪共鸣，让观众对号入座。
- **口播**：
  > 你是不是也这样：一上地铁就掏手机，短视频一条接一条，到站了脖子酸、眼睛花，啥也没记住；到了公司半天进不了状态，一天刚开始，人已经累了。时间不是没有，是被通勤路上悄悄刷没了。
- **画面/字幕提示**：插一段「地铁上全员低头刷手机」的空镜或演绎；字幕关键词「脖子酸」「进不了状态」。

## 三、价值点×3（15-45s，每条约10秒）

### 价值点 1（15-25s）：前一天晚上定好三件要事

- **口播**：
  > 第一，前一天晚上定好三件要事。别早上一睁眼才开始想今天干嘛，睡前花5分钟，写下明天必须干成的3件事。第二天一上通勤路，脑子是清空的、带目标的。
- **画面/字幕提示**：手机备忘录/便利贴写「明日三件事」的特写；角标「①」。

### 价值点 2（25-35s）：通勤路上只听行业播客不刷短视频

- **口播**：
  > 第二，通勤路上只听行业播客，不刷短视频。眼睛可以休息，耳朵不能闲着。刷视频是被动喂料，听播客是主动输入——同样40分钟，一个在下沉，一个在上涨。
- **画面/字幕提示**：收起短视频 App、戴上耳机听播客的演绎；角标「②」，字幕对比「刷视频 vs 听播客」。

### 价值点 3（35-45s）：到公司先花10分钟写当日清单

- **口播**：
  > 第三，到公司先花10分钟写当日清单。别一坐下就回消息，先把刚才路上想到的东西倒出来，整理成清单，再排优先级。这10分钟，决定你这一天是推着事走，还是被事推着走。
- **画面/字幕提示**：到工位第一件事打开文档列清单，微信弹窗先不管；角标「③」。

## 四、CTA（45-60s）

- **目标**：降低行动门槛 + 互动钩子 + 关注理由。
- **口播**：
  > 这三招不难，难的是明天就开始——先从今晚睡前写下3件要事做起。如果你也是通勤打工人，点个关注；评论区告诉我你单程通勤多久，下期我教你把通勤时间变成第二成长时间。
- **画面/字幕提示**：回到怼脸口播，结尾弹出「关注 + 评论区：你单程多久？」。
