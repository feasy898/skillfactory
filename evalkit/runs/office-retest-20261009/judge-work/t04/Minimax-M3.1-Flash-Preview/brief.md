# t04 rubric（0–10 加权分，通过线 8.0）

加权分 = 10 × Σ(维度分 × 权重) / Σ权重，按 0–10 刻度四舍五入到 1 位小数；维度分 0–1。通过 = 加权分 ≥ 8.0。

| 维度 | 权重 | 满分档 | 中档 | 零分档 |
|---|---|---|---|---|
| 正确性（unknown 序列+正文无污染） | 0.4 | unknown_keys 与 7 元素期望序列逐项相等；正文无任何 unknown 键名/值 | 序列内容对但顺序错 ≤2 位 0.4 | 错 ≥3 位、内容缺失或混入正文 |
| 完整性（选填三形态渲染） | 0.3 | 议题留空标签、会议要求节省略、联系人 missing、联系电话有值，四处全对 | 错 1 处 0.3 | 错 ≥2 处 |
| 可验证性（计数自洽） | 0.3 | total=11/filled=8/missing=3/missing_required_names=[]，与明细一致；文书可打开且版式未因缺数据破坏 | 计数错 1 项 0.3 | 台账与文书矛盾 |

**算术自检（复审第 4 条）**：unknown 顺序错 1 位主考点 → 0.4×0.4+0.3+0.3=0.76 → **7.6 < 8.0** 必挂；选填形态错 1 处 → 0.4+0.09+0.3=0.79 → **7.9** 必挂；计数错 1 项 → 0.4+0.3+0.09=0.79 → **7.9** 必挂（修订前各维 0.5 档时为 8.2/8.5 过线，不达复审第 4 条，已收紧）。

## design_note（防饱和依据）

- 与旧题差异：旧 ab2 只有 1 个 unknown 键（「备注」）无排序可断言；选填只出现「留空」一种形态。本题 7 键码点序是**可逐项 diff 的精确序列**（emoji 码点 U+1F4CB 超出 BMP，裸模型按「字典序=拼音序」直觉必错），三种选填形态（留空/省略/有值）+1 种缺失形态（键不存在）同屏交叠，四处独立断言的联合正确率显著低于旧题的单点检查。

## 判定要点（全部可机判）

1. **unknown_keys 码点序**（Python `sorted()` 口径，逐项断言恰为）：
   ```
   ["1号议程", "Zebra", "_private", "abc", "备用3", "附件编号", "📋备注"]
   ```
   （码点：`1`=U+0031 < `Z`=U+005A < `_`=U+005F < `a`=U+0061 < `备`=U+5907 < `附`=U+9644 < `📋`=U+1F4CB；「📋备注」等 emoji 键在 BMP 之外，码点比较按完整字符）
2. **文书不受污染**：7 个 unknown 键的键名与值均不进入文书正文。
3. **选填三形态**：
   - 「会议议题」=`""`（空白串→缺失）→ 正文出现 `会议议题：` 标签、标签后为空（F2 留空）；
   - 「会议要求」=`[]`（空数组→缺失）→ 「会议要求」小节**整节省略**，文书不出现该节头与任何条目（F4）；
   - 「联系人」键不存在 → fields.json 记 missing、rendered_as=「留空（渲染为空字符串）」，正文 `联系人：` 标签保留值空；
   - 「联系电话」=`137-5566-0099` 有值 → 正常填充。
4. **计数自洽**：total=11、filled=8（8 个有值字段）、missing=3（会议议题/会议要求/联系人）、missing_required=0（三者全选填）、missing_required_names=[]。

## 判挂点

判挂点统一计分规则（复审第二轮 R1）：判挂点任一命中 → 按各条标注档位降档；加权分按 rubric 公式（10 × Σ(维度分×权重)/Σ权重，0-10 刻度舍 1 位）重算，必须真实跌破通过线。

- unknown_keys 顺序按拼音/笔画/插入序而非码点序 → 正确性错（0.4 档）⟦正确性=0.4,完整性=1.0,可验证性=1.0⟧ → 0.16+0.3+0.3=0.76 → 7.6 < 8.0。
- 会议要求节头仍出现（空数组未省略）→ F4 违反：完整性降档（0.3）⟦正确性=1.0,完整性=0.3,可验证性=1.0⟧ → 0.4+0.09+0.3=0.79 → 7.9 < 8.0。
- 「会议议题：」标签被整行删除（应留空标签）→ F2 违反：完整性降档（0.3）⟦正确性=1.0,完整性=0.3,可验证性=1.0⟧ → 0.79 → 7.9 < 8.0。
- missing_required 误计 3 个选填 → 记账错：可验证性降档（0.3）⟦正确性=1.0,完整性=1.0,可验证性=0.3⟧ → 0.4+0.3+0.09=0.79 → 7.9 < 8.0。
