## 二、口播逐字稿

### 0｜钩子（0–4s，19 字）
> 全校闲置教材堆起来，能压出一座图书馆。

- 屏幕大字：**全校闲置教材 = 一座图书馆？**
- 画面：堆到房顶的旧书全景，快速推近
- 音效：低频「咚」+ 书本砸落声

### 1｜痛点（4–11s，35 字）
> 每到期末，大伙儿的书往楼道一扔就走了。我用一套循环，把书变成钱和流量。

- 画面：楼道里被书堵住的路 → 切回主播半身
- 身份锚点：**我 / 我这周 / 一晚清多少**（增加可信度）

### 2｜观点一 · 教材按学期末集中回收（11–28s，86 字）
> 第一步，踩准学期末这个时间窗。期末考完那几天是黄金期，一本书只有前两周值钱。学生刚考完就想甩，供给最集中，越往后越没人要。收书点摆在宿舍楼下，按斤称按捆收，一晚清两三百斤。

- 屏幕小字：学期末黄金窗口时间轴
- 数字钩子：前两周 / 两三百斤

### 3｜观点二 · 封面破损评级再定价（28–47s，99 字）
> 第二步，回收回来别一口价，我按封面破损分四档再定价。A 全新塑封折两成；B 轻微翻痕折四成；C 书角磨白压五折；D 缺页涂改按纸重算，两块钱一斤。
> 关键是，评级不是压价是分流：好书慢慢卖高价，破书当天打包走。

- 屏幕：**A / B / C / D 四档速查表**（停留 ≥4s，评论区截图素材）
- 反转点：先给分级标准，再抛「不是压价，是分流」

### 4｜观点三 · 跨界换书市集引流（47–63s，81 字）
> 第三步，光卖书还得把人引进来。我在旁边咖啡馆摆张换书桌，捐一本换一本，不收钱。第一天来的人一半为换书，一半是顺路进店的新客。换出去的每一本，都是下一轮的回收订单。

- 画面：咖啡馆换书桌实拍 → 人流走进店
- 屏幕小字：**换书桌 = 免费获客位**

### 5｜收束金句（63–71s，41 字）
> 所以二手书循环不是谁书多谁赢，是在对的时间、用对的价格、对的地方，把书和人转起来。

### 6｜互动引导（71–75s，20 字）
> 评论区报个学校名，我教你第一周怎么开局。

- 评论区置顶：「报学校名 + 省份，我按你们的放假时间排回收档期」

## 四、可复用性说明

三个 points 各自独立成段、互不依赖，可拆成三条 25–30s 的短视频单独投放，测试哪个钩子数据最好再合并成完整版。A/B/C/D 四档与价格折算可直接做成可复制的表格模板，是评论区承接的主要理由——因此 CTA 只索取「学校名」这一低成本动作，不索取联系方式。
