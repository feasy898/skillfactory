# 短视频 · 爆款骨架

- 主题：露营灯选购
- 平台模板：短视频分镜表（6 镜 45 秒：时间轴 / 画面 / 口播 / 字幕）
- 卖点输入：3 条（全部入槽 value_1..3 → shot_3/4/5）

> 本文件只给结构与开放槽位。所有 `【占位` 开头的槽位都是留给扩写环节的开放位，本阶段不编造内容填充；
> 拍板前需填入的实测/商品信息一律以占位槽位呈现，缺数据就让镜头改用替代画面，不要口头编数。

## 1. 开场钩子（00:00-00:03，3 秒，`shot_1`）

- 画面：夜营地桌面特写。一只手把一盏泛冷白光的露营灯怼近镜头，光斑扫过烤盘上的食物；手持轻微晃动，0.5 秒内完成推近。
- 口播：露营灯别乱买，这三个参数选错一个，晚上就翻车。
- 字幕：别乱买！3 个参数错一个就翻车
- `【占位:出镜人设】`（如：露营搭子 / 一号玩家 / 户外老炮）决定语气与镜头状态。
- > 写法要点：前 3 秒只做一件事——把「买错」的后果砸出来。不要在这镜里出现品牌、型号、价格，也不要做自我介绍；观众还没被钩住，任何品牌信息都是划走信号。口播用短句，句末带停顿，把「翻车」二字留给画面定格。

## 2. 痛点共鸣（00:03-00:10，7 秒，`shot_2`）

- 画面：三组翻车快剪，每组约 2 秒，同机位同构图不换景——① 惨白光下的肉色发灰；② 灯电量见底、画面骤暗；③ 一盏只能摆在桌上的灯，旁边是无处可挂的空树。
- 口播：灯太白，拍出来食物发灰；续航不够，半夜爬起来充电；想买能挂能吸的，又怕重。
- 字幕：显灰 / 半路没电 / 挂不上
- `【占位:营地场景地点】`（如：溪边营地 / 山谷草地）指定唯一出场地，换场景会削弱快剪对比的说服力。
- > 写法要点：痛点要「可见」不要「可讲」——三个痛点各配一个一眼能懂的画面，观众不用听声也知道在说什么。三组画面必须同机位同光线，只有色温/电量/摆放姿态在变，对比才成立。字幕用最短名词短语，不写句子。

## 3. 价值点一 · 色温（00:10-00:20，10 秒，`shot_3`）

- 画面：同一位出镜者、同机位、锁死曝光与白平衡的两组对照——左屏冷白光（7000K 档）打在食物上，右屏暖白光（约 3500K 档）打在同款食物上；两屏并排定格，右屏打勾。
- 口播：色温选 3500K 左右，暖白光最显食物本色，拍烤肉、拍热汤都出片。
- 字幕：色温 3500K 上下｜最显食物本色
- 卖点原文：色温选 3500K 左右最显食物本色
- `【占位:实测色温读数】`（对照机读数或参数页截图）
- `【占位:品牌型号A】`
- > 写法要点：价值点一给「数字 + 换算」而不是形容词——把 3500K 说成「冷白照菜、暖白显肉」这类人话对照，观众才能立刻判断自家那盏灯偏哪边。两屏对照必须锁曝光，否则观众会把亮度差误认成色温差。字幕只留数字与结论，结论那半句是这一镜的存档点。

## 4. 价值点二 · 续航（00:20-00:30，10 秒，`shot_4`）

- 画面：白天户外实拍：灯挂在支架上点亮，画面角落叠一张计时器与电量读数；镜头从灯摇向营地全景（天光 → 暮色 → 全黑），呈现时间流逝。
- 口播：别看参数表上的标称续航，按你实际要点亮的时长再多留一倍；通宵场就留两倍。
- 字幕：标称续航 ≠ 实测时长｜按实际 ×2 选
- 卖点原文：续航按高出实际时长一倍选
- `【占位:实测点亮时长】`（本条灯实测值 + 亮度档位）
- `【占位:标称续航对比】`（参数页数字）
- > 写法要点：价值点二给「算式」不给「参数」——把一句选购建议压缩成 `实际时长 ×2` 一个可复述的公式，观众截图就能用。天光流逝的转场是这一镜的密度来源，别剪碎；实测数字必须来自实测，对应占位槽位未填就整镜改成「天黑过程」的氛围镜头，不念数字。

## 5. 价值点三 · 固定方式（00:30-00:40，10 秒，`shot_5`）

- 画面：三连演示，同一盏灯依次——① 磁吸吸合在铁质支架/车体侧面并晃动两下；② 挂钩挂上树枝，灯体 360° 转正；③ 底座立回桌面。一镜三用，证明「双固定」。
- 口播：磁吸加挂钩双固定，树枝、支架、车体都能挂，一盏灯顶三种场景。
- 字幕：磁吸 + 挂钩｜双固定更百搭
- 卖点原文：磁吸加挂钩双固定更百搭
- `【占位:磁吸承重实测】`
- `【占位:挂钩承重实测】`
- > 写法要点：价值点三靠「一物多用」的并置画面取胜，不要用口播描述接口。承重测试若要出镜，必须全程实拍并用占位槽位标注承重读数；没有实测就不要演示承重，改为演示「挂得上、稳得住、角度可调」这一层结论。注意避开大风环境下的树枝演示。

## 6. 收尾 CTA（00:40-00:45，5 秒，`shot_6`）

- 画面：三盏同系列灯一字排开，主推款居中并加轮廓光；右下角浮出对比表缩略图占位。
- 口播：按这三条把参数对一遍，评论区扣「灯」，对比表我发你。
- 字幕：对完这三条再下单｜评论区扣「灯」
- `【占位:价格带】`
- `【占位:对比表领取方式】`
- > 写法要点：5 秒收尾只做一次转化动作，且必须给「一个词」的指令——评论区扣「灯」比「关注收藏」门槛低、也更利于下一条回复复用同一口令。不要在这一镜讲第二个理由，也不要念优惠力度；对比表图未做好就留空镜 + 口播，不承诺不存在的赠品。
