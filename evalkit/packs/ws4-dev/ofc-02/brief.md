# 任务：按公文版式生成一份请示函（含缺失字段处理）

## 输入

- `fixtures/input.json`：`{"template": "请示函", "title": <标题>, "fields": [...]}`。
- **注意：有必填字段的 `value` 为 `null`（缺失）**——这是本任务的常规情况，不是错误。

## 输出（写到 `out/` 目录）

**1. `out/文书.docx`（Word 文档）**，版式逐条执行：

- 第一段 = 标题（内容取输入 `title`），**居中对齐**；
- 第二段 = 称谓，段文本为 `主送单位值：`（值后接中文全角冒号），**顶格不缩进**；
- 正文每字段一段，段文本为 `字段名:值`（冒号用中文全角`：`），**每段首行缩进两字符（约 24 磅）**；
  - **缺失字段（value 为 null）的段落写 `字段名:____`**（四个半角下划线），不得编造值顶替、不得整段省略；
  - `主送单位` 只出现在称谓段，不重复进正文；
  - `落款单位`、`落款日期` 两个字段不进正文段；
- 最后两段为落款：第一段 = `落款单位` 的值，第二段 = `落款日期` 的值，两段均**右对齐**（只写值本身）；
- **字段值必须逐字照抄**：值中的全角括号 `（）`、书名号 `《》`、逗号等特殊字符一律原样保留，一个字符都不能变。

**2. `out/fields.json`**：

```json
{
  "template": "请示函",
  "title": <输入 title>,
  "filled_fields": [<已填字段名数组>],
  "missing_fields": [<缺失字段名数组>],
  "fields": [{"name", "required", "kind", "status", "value"}, ...]
}
```

- `status`：有值 = `"filled"`、值为 null = `"missing"`（value 保持 null）；
- `filled_fields`/`missing_fields` 分别与 `fields` 中两种 status 的字段名集合一致；
- **缺失记账与 docx 呈现必须一致**：`missing_fields` 里登记的每个字段，docx 中都应存在 `字段名:____` 的呈现。

## 判定要点（判定即按此执行）

- docx 可正常打开，内部无 `<!DOCTYPE`/`<!ENTITY` 声明；
- 标题居中、称谓顶格、正文缩进 20–28 磅档、落款右对齐；
- 每个已填字段值在 docx 中逐字出现；每个缺失字段以 `____` 呈现且登记在案——**替缺失字段编造值 = 不合格，静默丢弃字段 = 不合格**。

## 环境

- 可用 Python（python-docx 已安装）生成 docx；无需联网。
