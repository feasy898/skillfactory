# 任务：按公文版式生成一份会议通知（缺字段 + 边界值陷阱）

## 输入

- `fixtures/input.json`：`{"template": "会议通知", "title": <标题>, "fields": [...]}`。
- **两个陷阱，均为常规情况，按规约处理即可**：
  1. 有必填字段的 `value` 为 `null`（缺失）；
  2. 部分字段值含**全角字符**（如 `２０２６`、`３项`、`《》`）——必须原样逐字保留。

## 输出（写到 `out/` 目录）

**1. `out/文书.docx`（Word 文档）**，版式逐条执行：

- 第一段 = 标题（内容取输入 `title`），**居中对齐**；
- 第二段 = 称谓，段文本逐字为 `各部门：`，**顶格不缩进**；
- 正文每字段一段，段文本为 `字段名:值`（冒号用中文全角`：`），**每段首行缩进两字符（约 24 磅）**；
  - **缺失字段的段落写 `字段名:____`**（四个半角下划线），不得编造值、不得省略整段；
  - `落款单位`、`落款日期` 不进正文段；
- 最后两段为落款：`落款单位` 的值、`落款日期` 的值，两段均**右对齐**（只写值本身）；
- **字段值逐字照抄**：全角数字（`２０２６年１０月１５日` 之类）、书名号 `《》`、全角字符计数（`３项`）等一律原样保留——把它们「规范化」成半角即判不合格。

**2. `out/fields.json`**：

```json
{
  "template": "会议通知",
  "title": <输入 title>,
  "filled_fields": [...],
  "missing_fields": [...],
  "fields": [{"name", "required", "kind", "status", "value"}, ...]
}
```

- `status`：有值 = `"filled"`、null = `"missing"`；两个清单与 `fields` 两种 status 的字段名集合一致；
- 缺失记账与 docx `____` 呈现一一对应。

## 判定要点（判定即按此执行）

- docx 可正常打开，内部无 `<!DOCTYPE`/`<!ENTITY` 声明；
- 标题居中、称谓顶格、正文缩进 20–28 磅档、落款右对齐；
- 每个已填字段值在 docx 中**逐字符**出现（全角/半角一个不差）；缺失字段 `____` 呈现且登记。

## 环境

- 可用 Python（python-docx 已安装）生成 docx；无需联网。
